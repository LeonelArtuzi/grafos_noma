O que levar desta apresentação

CONCLUSÃO

É alcançabilidade

Coletar lixo é calcular quais vértices de um grafo dirigido são alcançáveis a partir das raízes.

Todo coletor escolhe o que pagar

Python paga em cada atribuição e recalcula graus de entrada. Java paga em barreiras e mantém índices de arestas.

Concorrência é invariante

Com o programa rodando, as barreiras protegem a regra: nenhuma aresta de preto para branco.
